# vscode-npm-scripts-yarn-repro

Minimal reproduction: which package manager runs a script changes with **how this directory is opened**.

## Layout

```
package.json               workspaces: ["packages/*"], has a "hi" script
package-lock.json          generated by npm
packages/cli/package.json  has its own "hi" script
repro.code-workspace       two folders: ROOT and packages/cli
```

No dependencies, no `yarn.lock`, no `.yarnrc.yml`, no `packageManager` field.

## Steps

```sh
npm install

code .                          # 1. open the folder
```

Open `packages/cli/package.json`, run the `hi` script, then close the window.

```sh
code .\repro.code-workspace     # 2. open the same directory through the workspace file
```

Run the same `hi` script in the same file.

## Output

**Folder (`code .`)** — runs through npm:

```
npm run hi
npm notice run @repro/cli@0.0.0 hi
npm notice run node -e "console.log('hello from packages/cli')"
hello from packages/cli
```

**Multi-root (`code .\repro.code-workspace`)** — ROOT still runs through npm, `packages/cli` is handed
to yarn:
